# MusicBox
MusicBox is a collection management app designed for users who own vinyl records, cassette
tapes, and CDs. It allows users to view digital versions of booklets containing lyrics and liner
notes. Users can save their collections, search for music releases, and access booklet content.
This helps prevent wear and damage to physical collections. MusicBox also links to music
apps for listening on mobile devices. It aims to reduce the time spent finding physical music
booklets by 50%.
