# Tech Stack & Hosting Strategy
## Defined Tech Stack
*   `HTML`: Used to create the basic structure and content of Music-Box
*   `CSS`: Design the layout and make the application responsive for both desktop and mobile devices
*   `JavaScript`: Implement interactive features such as collection management, music search, and digital booklet access.
*   `Local data storage`: Used to save users' collection information directly in their browsers.
## Hosting & Deployment Strategy
MusicBox will be hosted by GitHub Pages. Users will be able to access the application through a web browser using a GitHub Pages URL
